# Changelog

## 0.1.0 — source release candidate

- Standalone seeded LLVM IR transform and MSVC/Clang mixed-build pipeline.
- Partial-coverage/error reports and behavior/ABI/performance/size verification.
- CMake adapter, C++17/20 examples, six public regression tasks and executable scoring.
- Public documentation, source-only manifest/audit, Windows CI and third-party notices.

Known limits: not all benchmark groups meet balanced caps; the initial protected pilot was recovered; full isolated paired evaluation is incomplete. Bundled algorithms are public and cannot be treated as secret formal evaluation targets.
