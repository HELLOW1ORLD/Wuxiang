# Security and bypass reporting

Wuxiang v0.1 is a research prototype. It does not provide an OS sandbox, secret storage, DRM guarantees or proven anti-REA effectiveness. The local scorer executes native candidate code; use it only for trusted submissions unless independent OS isolation is supplied.

For sensitive vulnerabilities, use the repository's private vulnerability reporting feature when enabled under Security. Do not post credentials, proprietary binaries, recovered keys or private task sources in public issues. If private reporting is not enabled, open an issue requesting a private channel without the sensitive details.

Public protection bypasses using the bundled toy examples are useful research findings. Include the model/tool versions, method, behavior checks and relevant measurements. A bypass is not automatically a security vulnerability; equally, hiding it does not make the protection effective.
